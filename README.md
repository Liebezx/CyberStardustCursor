# CyberStardustCursor

An interactive **Cyber Stardust** cursor trail plugin for **BetterDiscord** with a built-in live preview editor.  

## Features

- **Live Preview Editor**: Test your trail directly inside the plugin settings modal (supports both mouse hover and an Auto-Demo figure-eight loop).
- **Full Customization**:
  - Trail length, max particle count, spark size, glow blur, spread, and opacity.
  - Particle shapes: **Circles**, **Stars**, and **Diamonds**.
  - 4 independent color slots (toggleable) + custom glow color.
  - Built-in presets: *Cyber Crimson*, *Liebe Mono & Gold*, *Cyber Emerald*, *Neon Cyan & Violet*.
- **Bilingual UI (EN / RU)**: Automatically matches your Discord language with a quick `EN / RU` toggle.
- **Zero Idle Load**: Automatically pauses `requestAnimationFrame` when no particles are active.

## Installation

1. Download [`CyberStardustCursor.plugin.js`](CyberStardustCursor.plugin.js).
2. Move it to your BetterDiscord plugins folder (`%appdata%\BetterDiscord\plugins` on Windows).
3. Enable **CyberStardustCursor** in **Discord Settings → BetterDiscord → Plugins**.
4. Click the **⚙️ (Settings)** icon on the plugin to customize the effect with live preview.
